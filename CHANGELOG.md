# Changelog

## [1.0.0] - 2026-10-02

First release.

- Cheap op-amp distortion (Dist, Tone, Level) with an ON footswitch and a light
- PULSE: switches the distortion on and off in 1/4, 1/8 or 1/16 notes, locked to the host tempo (free-runs at 120 BPM with no host clock), with a 3 ms crossfade
- Blackface-style clean 100 W combo: Volume, Treble/Middle/Bass (circuit-modelled tone stack), Bright switch
- Spring reverb, 6x10 cab voiced to a reference recording's clean guitar, old-tape saturation
- Amp + Cab bypass, INIT button, knob shortcuts
- 4x oversampled, VST3 and Standalone for Windows 64-bit
